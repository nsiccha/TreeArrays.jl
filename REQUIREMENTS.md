# Package scope

TreeArrays represents arrays and records with named dimensions. It supports
selection, reductions, and table or numeric-array views over rectangular and
ragged inputs. Arithmetic evaluates on the supplied leaves; the tree records
their structure and coordinates.

The [documentation](https://nsiccha.github.io/TreeArrays.jl/dev/) describes the
current API. Start with [named axes and records](docs/src/getting-started.md),
then [ragged inputs](docs/src/ragged.md) and [reductions](docs/src/reductions.md).
The [reference](docs/src/api.md) is generated from the current source.

## Prototype comparison

The `web/` application contains an earlier comparison of a DimensionalData
implementation and a standalone mock. Its inputs are generated by
`web/src/shared_data.jl` using a seeded random-number generator; it contains no
observed subject records. These prototypes are not the implementation of the
current TreeArrays API. Their timings are developer measurements and are not
claims made by the documentation site.

Current reduction benchmarks are described in [benchmark/README.md](benchmark/README.md).
No generated timings, plots, environment manifests, or sample arrays belong in git.
