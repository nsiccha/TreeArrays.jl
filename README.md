# TreeArrays.jl

TreeArrays reduces named dimensions in nested arrays, including records and
observations on different grids. It provides table and numeric array views for
plotting and downstream analysis.

Install from a Julia-enabled shell:

```sh
julia -e 'using Pkg; Pkg.add(url="https://github.com/nsiccha/TreeArrays.jl")'
```

| Task | Documentation |
| --- | --- |
| Run a first example | [Start](https://nsiccha.github.io/TreeArrays.jl/dev/) |
| Summarize and plot simulated curves | [Concentration trajectories](https://nsiccha.github.io/TreeArrays.jl/dev/trajectories) |
| Choose table or array views | [Interoperability](https://nsiccha.github.io/TreeArrays.jl/dev/tables) |
| Look up public operations | [API](https://nsiccha.github.io/TreeArrays.jl/dev/api) |

Documentation examples execute during the build. See [docs/README.md](docs/README.md)
for the page map and build instructions. Developer measurements are separate
from the documentation; see [benchmark/README.md](benchmark/README.md).
